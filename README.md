## Featured Projects

**[AmpTrail](https://github.com/AbdulFahad31/AmpTrail)** — Flutter · Firebase · Firestore · Mapbox
Real-time EV charging slot booking with role-based access control and Firebase Auth. Firestore-synced updates eliminate double-booking; includes a centralized admin dashboard with full CRUD across stations, bookings, and users. *Government of India Copyright Registered.*

**[ForensiAI](https://github.com/AbdulFahad31/ForensiAI)** — CrewAI · FastAPI · React · LLMs
AI-powered forensic investigation platform built in a 24-hour hackathon. Multi-agent CrewAI workflows automate case analysis and reporting; LLM-based anomaly detection cuts manual review effort by ~25%. *1st Prize — HackHere Hackathon (StartupTN affiliated).*

**[RoadCare](https://github.com/AbdulFahad31/RoadCare)** — Flutter · Supabase · Gemini AI · Mapbox
AI-powered road damage reporting app. Gemini 2.5 Flash auto-generates structured damage assessments from photos, classifying severity and estimating pothole dimensions. Supabase backend with Mapbox for location-based tracking.

**[Medovate](https://github.com/AbdulFahad31/medovate)** — Flutter · Firebase · FCM
Mobile-first doctor appointment booking platform with real-time availability and Firebase Cloud Messaging for appointment reminders.
